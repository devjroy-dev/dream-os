# PAPER C — THE IN-SCREEN LAYOUT GRAMMAR (the house rules, written once)

**ONE QUESTION:** can every future screen be judged against one page of rules? **FAILING OBSERVATION:** a new screen passes review while breaking a rule this page states.

1. **One primary action per screen, at the thumb's rest** *(Fitts)* — one gold-or-accent CTA, bottom third, 48px box; everything else is secondary dress. (The landing's five-decision entry is the cautionary specimen; the ruled L-B door is its cure.)
2. **Choices capped and chunked** *(Hick's)* — no decision point offers more than four peers; beyond four, group or defer (progressive disclosure). Menus order by use with the heaviest first and last *(serial-position)*.
3. **Progressive disclosure is the house's density instrument** — the Cabinet's rising sheet is promoted to the house idiom (R-X22 made it the chat's physics too): summary on the surface, depth one lift away, never eleven states in one panel.
4. **Recognition over recall, on every label** — a word predicts its destination in plain speech (*Storefront* opens the storefront; the Studio-opens-the-calendar class is extinct by rule); internal nouns never in chrome (the Maker/Dreamer and persona laws restated as one sentence).
5. **States are always legible** — the F-09.21 pressed primitive on every interactive element; 44px minimum touch boxes (F-09.22); loading is skeleton, never blank; **failure is a rendered state with a retry, never an empty collection** (F-09.23's port, house-wide); empty states carry a next action or the labeled first-run exemplars (R-X23's chapter), and zero-collapse governs — absent sections render nothing.
6. **The register laws are layout laws too** — money `Rs X,XX,XXX` (never ₹, never L/k/Cr), one date voice, the type scale and 16px body floor per the ruled canon, gold never text.
7. **Baseline discipline** — same-line text aligns on baseline with the shared line-height; glyphs sit in fixed slots (the R-X24 Row primitive, every row's inheritance).
8. **THE HONESTY BOUND, over everything** *(restated because the charter restates it)* — persuasion is true things well-placed: no fake urgency or scarcity, no confirm-shaming, no pre-checked consent, no progress that didn't happen, no social proof that isn't literally true. A screen that needs a dark pattern to work is a screen that doesn't work.

**Enforcement shape** (so this page has teeth, not vibes): rules 1–2 and 5–7 are greppable/benchable and join the canon's audit gates; rules 3–4 and 8 are review-gate sentences the chair applies at every UI read-first — named here so no future sitting re-litigates them from scratch.
